      管理

      按功能分组：常规设置 · 安全与账号 · 集成服务 · 备份迁移

      站点信息

      保存后对前台立即生效
      默认 admin，可改成 2–24 位小写字母 / 数字 / 短横线；改完用新地址访问后台，旧的 /admin 会 302 跳过去。

      前台栏目

      拖动左侧 ⋮⋮ 调整顺序 · 开关即时生效 · 可改名称与图标

      关闭的栏目会从前台侧边栏与移动端导航中隐藏，直接访问会提示「栏目已关闭」。拖动可调整先后顺序（前台导航、后台侧边栏同步生效）。图标支持内置图标与自行上传（PNG / JPG / SVG / WebP）。

        页脚与备案

        留空即不显示 · 保存后前台立即生效

        社交链接

        显示在首页标题下方 · 清空即隐藏该项

        搜索引擎推送

        未启用

        IndexNow 会在文章发布 / 删除后立刻通知 Bing、Yandex、Seznam、Naver（Google 不支持该协议，仍靠 sitemap 抓取）。 密钥为 8–64 位字母、数字或短横线，可用 openssl rand -hex 16 生成。

        还需要把内容等于密钥的文本文件 密钥.txt 放到前端根目录一起部署，否则搜索引擎无法验证密钥。

        瞬间同步

        未启用

        开启后，新建或编辑「瞬间」会自动发到 Telegram 频道，删除时同步撤回。 内容里的图片会一起发送（最多 4 张）。需要一个 Bot：在 Telegram 里找 @BotFather 建机器人拿 Token，把机器人拉进频道并给「发消息」权限，频道 ID 形如 @your_channel 或 -1001234567890。

        外部域名白名单

        前台点外链时，只有名单内的域名会直接跳转

        默认包含代码内置的几个域名。这里增删的域名保存在后端，前台刷新后立即生效。只填域名即可（如 example.com），不要带 https:// 与路径；子域名无需单独添加。

                  数据迁移
                  
                V1 · 文件存储
              
                  
              
                  当前版本（V1）把文章存成磁盘上的 Markdown 文件。这里可以把整站搬到两个新版本：V2 = 前后端分离 + SQLite（前端放 Cloudflare，后端一个 Node 进程）；V3 = 前后端不分离 + SQLite（单进程 SSR，像 Typecho 一样）。也支持和 Hugo / Hexo / Jekyll / Astro / Ghost / Obsidian 互相搬运 Markdown。
