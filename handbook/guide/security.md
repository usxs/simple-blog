# 安全设置

后台「管理 → 账号安全」有四张卡：管理员账号、两步验证、通行密钥、登录会话。

## 管理员账号

改用户名或密码，都需要输入当前密码。改完会**吊销其它设备会话**，当前会话自动续上。

## 两步验证（TOTP）

1. 点「开始设置」，页面给出密钥和 `otpauth://` 链接。
2. 用验证器 App（1Password、Google Authenticator、Authy…）扫链接或手动输入密钥。
3. 填入 App 上的 6 位数字 → 启用。
4. 记下 10 个一次性**备用码**（每个只能用一次，登录时可替代验证码）。

关闭两步验证需要输入当前密码。

## 通行密钥（Passkey）

- 「添加通行密钥」→ 浏览器弹指纹/Face ID/系统 PIN → 注册完成。
- 可以给同一账号注册多个设备。
- 登录页会出现「使用通行密钥登录」，点一下走系统验证。
- 删除某个通行密钥需要输入当前密码。

!!! warning "HTTPS 是硬性要求"
    WebAuthn 只在 HTTPS（或 `localhost`）下可用；反代时 `X-Forwarded-Proto` 必须传递。

## 登录会话

| 分组 | 说明 |
| --- | --- |
| 会话 | 当前有效的登录，绿点 = 3 分钟内有请求（在线）；当前设备带「当前」标记 |
| 历史会话 | 已退出 / 被踢 / 过期的记录，保留最近 80 条 |
| 黑名单 | 被封禁的 IP 或设备 |

点一条会话展开详情：IP、归属地（懒加载）、设备与浏览器、在线时长、首次登录、最近活动、完整 User-Agent。

可做的操作：

- **改备注**：给设备起个好认的名字（如「家里的 Mac」）
- **踢下线**：立即失效，对方下一个请求就是 401
- **封禁 IP / 设备**：写入黑名单，之后该 IP/设备登录直接 403
- **解除封禁**：在黑名单分组里

## 其它安全措施

- 密码用 scrypt（N=16384）加盐存储，校验恒定时间
- 非 GET 请求校验 `Origin` / `Sec-Fetch-Site`，跨站一律 403
- 登录失败按 IP 限流，连续 5 次锁 15 分钟
- `data/` 下敏感文件权限 0600
- 数据目录不可写时接口返回 503 并给出修复提示，不会让进程崩溃
