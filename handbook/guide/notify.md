# 通知推送

两种渠道：**邮件**（SMTP，任何服务商都行）和 **Bark**（iOS 推送）。都在后台「推送」里配置。

## 发给访客 vs 发给站长

| 事件 | 收件人 | 渠道 |
| --- | --- | --- |
| 评论收到回复 | 留言者（填了邮箱） | 只走邮件 |
| 友链审核结果 | 申请人（填了邮箱） | 只走邮件 |
| 新评论 | 站长 | 邮件 + Bark（按勾选） |
| 新友链申请 | 站长 | 邮件 + Bark（按勾选） |
| 后台登录爆破 / 验证码被刷 | 站长 | 邮件 + Bark（按勾选） |

站长的两个渠道用「推送渠道」里的勾选框控制，关掉哪个就不发哪个。

## 邮件（SMTP）

后台「推送 → 邮件」，填：

| 字段 | 示例 |
| --- | --- |
| 服务器 | `smtp.example.com` |
| 端口 | `465`（SSL）/ `587`（STARTTLS） |
| SSL | 465 勾选，587 不勾 |
| 用户名 | `noreply@example.com` |
| 密码 | 授权码，不是登录密码 |
| 发件人 | `noreply@example.com` |
| 发件人名 | `简单博客` |

保存后点「发送测试邮件」，收件箱收到就说明通了。

!!! tip "常见报错"
    - `找不到这个 SMTP 服务器` → 域名拼错，或服务器出网 465/587 被拦
    - `535` → 用户名/授权码不对，很多邮箱需要用「授权码」
    - `ECONNREFUSED` → 端口与 SSL 不匹配（465 配了非 SSL 之类）

## Bark

后台「推送 → Bark」，填服务器（默认 `https://api.day.app`）、设备 Key，可选分组、提示音与级别（`active` / `passive` / `timeSensitive` / `critical`）。

保存后点「发送测试推送」，手机上收到就通了。

## 模板

「推送 → 模板」分三组：

- **发给访客 · 邮件**：`评论回复`、`友链审核结果`
- **发给我 · 邮件**：`新评论`、`新友链申请`、`安全提醒`
- **发给我 · Bark**：`新评论`、`新友链申请`、`安全提醒`

可用变量：`{{site}} {{name}} {{title}} {{url}} {{content}} {{time}} {{status}} {{replier}} {{reason}} {{reasonLine}} {{link}}`。

每个模板都能「恢复默认」。邮件会自动套上黑白版式：深色外框 + 浅色正文卡片 + 站点头像与名称。
