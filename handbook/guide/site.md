# 站点配置

后台「管理」页集中了所有影响外观的设置，改完**立刻生效**（前端会从 `/api/site` 同步，并缓存在浏览器本地）。

## 站点信息

| 项 | 说明 |
| --- | --- |
| 站点名称 | 侧边栏、页脚、浏览器标题 |
| 头像文字 | 1–2 个字符，显示在侧边栏圆形头像与 favicon |
| 网页标题 | 首页 `<title>` |
| 副标题 | 首页一句话介绍，也用作默认 meta description |
| 后台入口 | 默认 `admin`，可改成任意 2–24 位小写字母/数字/短横线 |

## 前台栏目

一共 8 个：首页、文章、瞬间、友链、工具、探针、状态、奇奇怪怪。

每一项可以：

- **开关**：关闭后前台侧边栏、移动端底栏、后台侧边栏都隐藏；直接访问该路径显示「栏目已关闭」，sitemap 也不再收录
- **改名**：最长 12 字
- **换图标**：16 个内置图标任选，或上传自己的图片（自动转 WebP），也可以填外链
- **改路径**：比如把 `/moment` 改成 `/diary`，sitemap 和导航同步更新

拖动左侧 `⋮⋮` 可以调整顺序，前台侧边栏、移动端底栏、后台侧边栏三处一起变。

「首页」不能关闭，但可以改名换图标。

## 页脚与备案

| 项 | 说明 |
| --- | --- |
| ICP 备案号 | 例如 `京ICP备2026000001号-1`，填了就显示一枚盾形图标，点击跳 `beian.miit.gov.cn` |
| 公安备案 | 例如 `京公网安备 11010502030146号`，会自动从号码里提取数字拼查询链接 |
| 萌 ICP | 来自 <https://icp.gov.moe/>，填号后点击跳该站查询 |
| 补充说明 | 一行自定义文字，例如「本站由 简单博客 驱动」 |
| 版权声明 | 开关，控制侧边栏底部的「© 年份 站名 · All Rights Reserved.」 |

徽章只显示图标（24×24 单色），鼠标移上去浮窗显示具体号码。三个备案号留空就整枚隐藏；页脚在侧边栏底部，移动端不显示。

## 社交链接

首页主区域的 GitHub / X / Telegram / 邮箱，填了才显示图标，留空整行隐藏。邮箱会自动补 `mailto:`。

## 索引推送（IndexNow）

填密钥 → 保存 → 「检查密钥文件」验证 `https://www.example.com/<密钥>.txt` 是否可访问。详情见 [SEO](../start/seo.md#3-indexnow可选加速收录)。

## 探针

两种数据源可选：**CF-Server-Monitor**（`/api/servers`）与**极简探针 monitor**（`/api/nodes`），填地址与面板地址即可。关闭后前台显示「探针未启用」。
