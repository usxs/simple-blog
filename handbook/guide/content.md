# 写文章与瞬间

内容以 Markdown 保存。V1 把每篇文章写成服务器上的文件；V2 / V3 把 Markdown 原文存进 SQLite 的正文列，不转成 HTML。图片与附件在三个版本里都仍然落在磁盘上。

## 文章

后台「文章」页点「新建文章」进入写作页，字段：

| 字段 | 说明 |
| --- | --- |
| 标题 | 文章标题；新建时由它生成链接 ID |
| 链接 ID | URL 的一部分，保存后不可改 |
| 日期 | 决定排序（**按日期倒序**，不是按修改时间） |
| 标签 | 可填多个，用逗号 / 顿号 / 空格分隔，例如 `折腾, macOS`；列表右侧统计栏上方会列出全部标签 |
| 正文 | Markdown；工具栏有 H1/H2/H3、粗体、斜体、删除线、大写、引用、代码、链接、图片、列表、加密片段、解除片段 |

### 三种视图

写作页顶部可以在三个视图之间切换，默认「内容」，选择会记在浏览器里：

| 视图 | 布局 | 适合 |
| --- | --- | --- |
| **内容** | 只有 Markdown 源稿 | 连续写作、批量修改 |
| **预览** | 只有渲染结果 | 校对排版、图片与代码块 |
| **对照** | 左边源稿，右边预览 | 边改边看 |

快捷键是 <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd>；窄屏下「对照」会改为上下堆叠。

保存后的位置：

- **V1**：`article/<id>/<id>.md`，评论在 `article/<id>/comments.json`（有评论时才生成）；`<id>` 由标题清洗而成（去掉 `\ / : * ? " < > |` 与首尾空格，中文保留）。
- **V2 / V3**：正文与评论存在 `data/blog.db`，正文列里仍是 Markdown 原文。
- 三个版本的图片、附件分别在 `img/`、`file/`。

## 隐藏文章

写作页勾选「在前端隐藏」：文章保留在后台、可以随时取消勾选恢复，但前台列表、搜索、`/api/public/post/<id>` 都看不到（匿名访问 404），直接访问旧链接也打不开。后台列表里会标「已隐藏」。

## 加密

**整篇加密**：写作页打开「整篇加密」并设置访问口令。前台打开文章只看到标题和锁面板，输入正确口令后才拉取正文。

后台打开加密文章时，如果服务器还保存着口令，会先自动解密，正文可以直接编辑，顶部状态显示「后端已自动解密 · 前台仍需口令」；只有状态显示「已加密 · 输入口令后解锁正文」时才是只读的，需要输入一次口令。保存时口令留空表示沿用原口令，既不会丢加密，也不会把密文覆盖成明文。口令不要和登录密码一样。

**片段加密**：选中正文里的任意文字或图片，点工具栏「加密片段」，设置口令后这段内容在正文里只存 `:::locked` 密文，前台显示为一块上锁的区域，输入口令才展开。同一篇文章里可以有任意多个加密片段，口令可以各不相同。

需要改回明文时点「解除片段」：后台会扫描正文里的 `:::locked` 区块，逐个用对应口令解密并替换回明文，再保存即可。片段口令同样无法找回。

两种加密共用一套口令校验接口和错误次数限制；忘记口令无法找回（不要只留密文备份）。

## 瞬间

「瞬间」是短内容（类似微博），字段只有日期、标签、正文：

V1 存成 `Musings/<id>.md`；V2 / V3 存在 `data/blog.db`，正文同样是 Markdown 原文。

可以配置 Telegram 同步：后台「推送 → 瞬间同步」，绑定 Bot 与频道后，发布/修改/删除瞬间会同步发消息 / 撤回消息。图片来自正文里的 Markdown 图片链接（最多 4 张）。

## Markdown 支持

- 标题（`#` 渲染为 `h2`，`##` 为 `h3`）、粗体/斜体/删除线/`==高亮==`
- 有序/无序/任务列表，支持嵌套
- 表格（含对齐）、引用（可嵌套）、分隔线
- 代码块：语言标签、行号、复制、放大灯箱
- 图片：点击灯箱查看
- Mermaid 流程图：```` ```mermaid ```` 围栏

## 图片与附件

- 编辑器里的「插入图片」上传后会**自动转 WebP 并压缩**（长边最大 2560px，质量 82），原图不保留。
- 图片存 `img/<日期>/`，附件（任意文件）存 `file/<日期>/`。
- 文件名格式：`时间戳-原名.webp`，同名冲突自动加 `-1`、`-2`。
- 站点不提供外链图床，也不需要：链接直接指向自己的域名。

!!! tip "想保留原格式"
    启动时加环境变量 `IMAGE_WEBP_DISABLE=1` 即可全局关闭转换（GIF 动图会退化为静态 WebP，介意就关掉）。

## 排序与展示

列表按 **日期** 倒序；同一天再按修改时间。所以想让某篇置顶，把它的日期写晚一点即可。
