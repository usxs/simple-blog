# 写文章与瞬间

内容全部是 Markdown，落盘在服务器上，不进数据库。

## 文章

后台「文章 → 新建」，字段：

| 字段 | 说明 |
| --- | --- |
| 标题 | 文章标题，也是 URL 的一部分 |
| 日期 | 决定排序（**按日期倒序**，不是按修改时间） |
| 标签 | 单个标签，显示在列表与文章页 |
| 正文 | Markdown |

保存后文件位置：

```
article/<id>/<id>.md
article/<id>/comments.json   # 该文的评论（有评论时才生成）
```

`<id>` 由标题清洗而成（去掉 `\ / : * ? " < > |` 与首尾空格，中文保留）。

## 瞬间

「瞬间」是短内容（类似微博），字段只有日期、标签、正文：

```
Musings/<id>.md
```

可以配置 Telegram 同步：后台「推送 → 瞬间同步」，绑定 Bot 与频道后，发布/修改/删除瞬间会同步发消息 / 撤回消息。图片来自正文里的 Markdown 图片链接（最多 4 张）。

## Markdown 支持

- 标题（`#` 渲染为 `h2`，`##` 为 `h3`）、粗体/斜体/删除线/`==高亮==`
- 有序/无序/任务列表，支持嵌套
- 表格（含对齐）、引用（可嵌套）、分隔线
- 代码块：语言标签、行号、复制、放大灯箱
- 图片：点击灯箱查看
- Mermaid 流程图：```` ```mermaid ```` 围栏

## 图片与附件

- 编辑器里的「插入图片」上传后会**自动转 WebP 并压缩**（长边最大 2560px，质量 82），原图不保留。
- 图片存 `img/<日期>/`，附件（任意文件）存 `file/<日期>/`。
- 文件名格式：`时间戳-原名.webp`，同名冲突自动加 `-1`、`-2`。
- 站点不提供外链图床，也不需要：链接直接指向自己的域名。

!!! tip "想保留原格式"
    启动时加环境变量 `IMAGE_WEBP_DISABLE=1` 即可全局关闭转换（GIF 动图会退化为静态 WebP，介意就关掉）。

## 排序与展示

列表按 **日期** 倒序；同一天再按修改时间。所以想让某篇置顶，把它的日期写晚一点即可。
