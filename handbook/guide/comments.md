# 评论与审核

评论默认**需要审核**：访客提交后进「待审核」，站长在后台通过后才显示。

## 访客侧

- 昵称、邮箱（选填，用于接收回复通知）、个人主页（选填）
- 算术验证码（`12 + 7 = ?`），10 分钟内有效、一次性
- 支持对已有评论回复（楼中楼，最多两层）
- 防刷：同 IP 30 秒一条、每小时 8 条、每天 30 条；验证码 10 分钟最多 30 次

## 站长侧

「评论审核」分三组：

| 状态 | 说明 |
| --- | --- |
| 待审核 | 新评论，点「通过」后公开 |
| 已通过 | 已展示，可驳回或删除 |
| 已驳回 | 不展示，可再通过 |

每条评论都能**直接回复**，回复内容会以「站长」身份展示，并（配置了邮件时）通知留言者。

## 通知

配置了邮件/Bark 后：

- 有新评论 → 站长的邮件（`新评论` 模板）+ Bark（按「推送渠道」勾选）
- 站长回复 → 留言者收到邮件（`评论回复` 模板，标题会写「站长 回复了你在《xxx》下的留言」）

详见 [通知推送](notify.md)。

## 数据在哪

```
article/<id>/comments.json
```

结构是 `{ comments: [...] }`，字段含 `author`、`content`、`replyContent`、`ip`、`date`、`status`。想批量处理可以直接改文件（改完刷新后台即可）。
