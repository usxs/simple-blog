# 友链

前台 `/links` 页展示已通过的友链，右上角「加入友链」进入 `/links/apply`，访客自助提交、站长审核。

## 访客填写

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 网站地址 | ✅ | 自动补 `https://`，只接受 http(s) |
| 网站名称 | ✅ | 最长 30 字 |
| 图标地址 | | 填外链即可，**不占本站空间**；留空用网站名首字 |
| 邮箱 | | 选填，审核结果会发到这里 |
| 一句话介绍 | | 最长 80 字 |

提交后进「待审核」，页面提示「等站长审核通过后就会出现在友链页」。

## 站长审核

后台「友链」分三组：待审核 / 已通过 / 已驳回。

- **通过**：出现在前台，通知申请人（配了邮件时）
- **驳回**：需要填原因（最长 120 字），原因会写进通知邮件，前台不展示
- **编辑**：改名称、地址、图标、邮箱、备注
- **删除 / 下架**：从列表移除或退回未展示状态

「新增友链」可以自己加，图标支持**上传图片**（和其他上传一样自动转 WebP），也可以直接填外链。

## 限制

- 同一地址不能重复提交（已通过提示「已经在友链里了」，待审提示「已经提交过申请」）
- 每 IP 10 分钟内最多 2 次、每小时 5 次
- 带隐藏蜜罐字段，机器人填写会被静默丢弃
