# 登录与后台

后台地址：`https://api.example.com/<后台入口>`（默认 `admin`，可在「管理 → 站点信息」里改）。

## 首次初始化

两种方式任选其一：

1. 容器启动时通过环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 创建；
2. 直接打开后台地址，会出现**初始化页面**，填一次用户名与密码（≥8 位）即可。

初始化成功后 `data/auth.json` 生成，两个环境变量就失效了——之后改账号密码只能在后台进行。

## 登录

- 支持**两步验证码**：开启后登录页会多出一个「验证码」框（6 位数字）。
- 支持**通行密钥**（Passkey）：登录页的「使用通行密钥登录」按钮，需要浏览器支持（Safari、Chrome、Edge 均可）。
- 连续输错 5 次会锁 15 分钟，并触发一次「后台登录被反复尝试」通知。
- 会话 Cookie 是 `HttpOnly + SameSite=Strict`，HTTPS 下再加 `Secure`；滑动有效期 7 天，最长 30 天。

## 侧边栏

| 入口 | 作用 |
| --- | --- |
| 文章 | 写/改/删文章，列表按发布时间倒序 |
| 瞬间 | 短内容，支持同步到 Telegram 频道 |
| 评论审核 | 待审核 / 已通过 / 已驳回，可回复 |
| 友链 | 审核申请、手动新增、改备注、下架 |
| 推送 | 邮件与 Bark 配置、8 个通知模板 |
| 工具 / 状态 / 奇奇怪怪 | 站点里的三个自定义栏目（可在「前台栏目」里改名或关闭） |
| 探针 | 服务器探针数据源（CF-Server-Monitor / 极简探针） |
| 管理 | 站点信息、前台栏目、页脚备案、社交链接、账号安全、索引推送 |

「管理」的二级菜单会把鼠标放上去展开，点击左侧图标进入页面，点击右侧小三角把菜单固定住。

## 忘记密码

后台没有「找回密码」，需要在服务器上改 `data/auth.json`：删掉该文件会清空账号（下次登录重新初始化）；只想改密码的话，删除文件更省事——**注意这会一并清掉两步验证和通行密钥**，但文章、评论、友链不受影响。

## 退出

右上角「退出登录」，会吊销当前会话 Cookie。
